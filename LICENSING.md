# Licensing

Two licences cover this repository, each by kind. The code is licensed under the [Apache License 2.0](LICENSE), and the reports, the plans, the configurations and the transcripts under [Creative Commons Attribution 4.0 International](LICENSE-CC-BY-4.0).

| What | Where | Licence |
|---|---|---|
| The harnesses, the analyses and their tests | `*/*.py` | Apache-2.0 |
| The plans, the reports, the configurations, the system prompts and the transcripts | `*/*.md`, `*/*.json`, `*/*.txt`, `*/transcripts/` | CC BY 4.0 |
| The documents at the root | `README.md`, `LICENSING.md` | CC BY 4.0 |

The transcripts hold what the models answered, Claude Haiku 5.5 in the game and the fresh hearers, Gemini and GPT among them, in the decoding test. The system prompt of each experiment quotes the skill, the grammar summary, the lexicon listing and the specification of [Rowih](https://github.com/rowih/rowih), which are licensed under CC BY 4.0 there.

A work that uses the reports or the data credits them as *Rowih experiments* with a link to this repository, <https://github.com/rowih/experiments>, and states whether it changed them.
